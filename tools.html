Toolkit

Ten tools behind the outputs.

Nothing exotic and nothing hidden: an environment to run notebooks, an editor to write them, four libraries that do the actual work, and two utilities for the database and the repository. Each links to its own documentation rather than somebody's tutorial.

04 tools · the actual work
pandas

The backbone of every experiment here — DataFrames, I/O, cleaning, reshaping and the SQL bridge in EXP-2.

Docs
NumPy

Arrays, vectorised arithmetic, NaN handling and the random data used for the outlier work in EXP-3.

Figures, subplots, annotations and every base chart in EXP-5 — including the grouped and stacked bar variants.

Statistical plots in a single line — histograms with KDE, box plots, scatter with hue, and the iris pairplot.

Data & versioning

02 tools · keeping the record straight
DB Browser for SQLite

Opens students.db from EXP-2 so the tables can be inspected outside the notebook — useful when a query returns something unexpected.

Docs
Git & GitHub

Version control for the record — notebooks, datasets and charts live in a repository, so a broken experiment can always be compared to a working one.

Docs Profile
Why these

Every tool here is free to use and documented publicly. The list is short on purpose: a lab record is easier to trust when you can install the same ten things and re-run the notebook yourself.
